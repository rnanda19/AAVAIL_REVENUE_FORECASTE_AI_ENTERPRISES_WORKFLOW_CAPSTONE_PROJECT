# Pomodoro Clock

A simple desktop Pomodoro timer built with Python's Tkinter.

## Usage

```bash
python3 pomodoro.py
```

- 25-minute work sessions
- 5-minute short breaks after each work session
- 15-minute long break after every 4 work sessions
- Click **Start** to begin/resume, **Reset** to clear the timer
- Checkmarks track completed work sessions
